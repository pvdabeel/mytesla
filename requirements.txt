# mytesla-xbar runtime dependencies.
#
# Install with:
#     pip3 install --user -r requirements.txt
#
# Notes:
#   * Versions are intentionally permissive — mytesla only uses small,
#     stable subsets of these libraries. If a future major release
#     breaks something, pin to the previous major here.
#   * `keyring` shells out to the macOS Security framework on Darwin,
#     so no extra system packages are required.
#   * `pyobjc-framework-WebKit` is what powers the embedded Tesla
#     sign-in window. We host the Fleet API sign-in inside a WKWebView so
#     captcha/MFA/passkey prompts all work and we can capture the auth
#     code from the redirect in-process. Without this package we fall back
#     to a copy/paste flow.
